1. PRZEGLĄD SYSTEMU
================================================================================

PV Planner to system optymalizacji zarządzania baterią magazynu energii dla
instalacji fotowoltaiki z pompą ciepła.

PRZEPŁYW DZIAŁANIA:
  Dzisiaj (D):
    ├─ initialize() - wczytaj plan na D i D+1
    ├─ trigger - oblicz plan na D+1
    └─ 22:00 - _start_executor()
  
  Jutro (D+1):
    ├─ 22:00 - Wysyłanie programów do falownika
    └─ Sterowanie baterią przez całą noc/dzień

ETAPY PRACY:
  1. SNAPSHOT - odczyt ~30 encji z HA (pogoda, bateria, PV, pompa ciepła)
  2. PLANNER CORE - symulacja 24h, obliczenie SOC_06 i SOC_13
  3. PLAN STORE - zapis do SQLite
  4. EXECUTOR - wysyłka programów do falownika

3. PARAMETRY KONFIGURACJI
================================================================================

Wszystkie parametry znajdują się w config.py

WSPÓŁCZYNNIKI PV:
  PV_BEFORE_13_RATIO = 0.60       # 60% energii PV przed 13:00 (domyślnie)
  PV_AFTER_13_RATIO = 0.40        # 40% energii PV po 13:00 (domyślnie)

OFFSETY CZASOWE SŁOŃCA:
  PV_DAWN_OFFSET_MIN = 45         # Start produkcji: wschód + 45 min
  PV_DUSK_OFFSET_MIN = 30         # Koniec produkcji: zachód - 30 min

LIMITY CZASOWE PROGRAMÓW:
  PROGRAM_3_EARLIEST_HOUR = 6     # Program 3 najwcześniej o 6:05
  PROGRAM_3_EARLIEST_MIN = 5      # (parsowane z input_text.pv_planner_program_3_earliest_time)
  PROGRAM_6_EARLIEST_HOUR = 15    # Program 6 najwcześniej o 15:05
  PROGRAM_6_EARLIEST_MIN = 5      # (parsowane z input_text.pv_planner_program_6_earliest_time)

PROFILE ZUŻYCIA DOMU:
  HOUSE_LOAD_PROFILE = {
    "night": 0.4,                 # 0-6h: 0.4 kW
    "morning_day": 0.6,           # 6-15h: 0.6 kW
    "evening": 1.6,               # 15-20h: 1.6 kW
    "night_late": 1.0             # 20-24h: 1.0 kW
  }

TARYFY PRĄDOWE:
  CHEAP_TARIFF_WINDOWS = [
    (22, 6),                       # 22:00-06:00 (noc)
    (13, 15)                       # 13:00-15:00 (midday)
  ]

MOC POMPY CIEPŁA (w zależności od temperatury):
  HEAT_PUMP_POWER_AT_PLUS_15 = 1.0   # 1.0 kW @ +15°C
  HEAT_PUMP_POWER_AT_PLUS_10 = 1.0   # 1.0 kW @ +10°C
  HEAT_PUMP_POWER_AT_PLUS_5 = 1.0    # 1.0 kW @ +5°C
  HEAT_PUMP_POWER_AT_0 = 1.0         # 1.0 kW @ 0°C
  HEAT_PUMP_POWER_AT_MINUS_5 = 1.0   # 1.0 kW @ -5°C
  HEAT_PUMP_POWER_AT_MINUS_10 = 1.0  # 1.0 kW @ -10°C
  HEAT_PUMP_CONSUMPTION_MODEL = "Standard"  # Standard / Premium / Eco
  HEATING_SEASON_ACTIVE = True       # Czy sezon grzewczy jest aktywny

FUNKCJE HELPER:
  get_house_load(hour)            # Zwraca zużycie dla danej godziny
  is_cheap_tariff(hour)           # Sprawdza czy godzina jest w taniej taryfie

4. INSTALACJA W HOME ASSISTANT
================================================================================

KROK 1: Dodaj encje do Home Assistant
----------------------------------------

SPOSOB A: Automatycznie (REKOMENDOWANY)

Skopiuj zawartość apps/pv_planner/homeassistant_config.yaml i wklej do configuration.yaml:

!include apps/pv_planner/homeassistant_config.yaml

LUB dodaj bezpośrednio zawartość pliku.

SPOSÓB B: Ręczny przegląd elementów

Powinna zawierać:
  ✓ 12 encji input_number (PV ratios, offsets, house load, heat pump power)
  ✓ 2 encje input_text (program 3/6 time w formacie HH:MM)
  ✓ 2 encje input_select (tariff windows, heat pump model)
  ✓ 1 encja input_boolean (heating season active)
  ✓ 1 template sensor (wyświetlanie parametrów)
  ✓ 1 automation (trigger do AppDaemon)

KROK 2: Restart Home Assistant
---------------------------------------

Developer Tools → YAML → Restart Home Assistant

Lub w terminalu:
  docker restart homeassistant

KROK 3: Zweryfikuj encje w HA
---------------------------------------

Settings → Devices & Services → Helpers

Powinieneś zobaczyć (z prefixem "pv_planner_"):
  ✓ input_number: pv_before_13_ratio, pv_after_13_ratio, pv_dawn_offset_min,
    pv_dusk_offset_min, house_load_night/morning_day/evening/night_late,
    heat_pump_power_at_plus_15/plus_10/plus_5/0/minus_5/minus_10
  ✓ input_text: program_3_earliest_time, program_6_earliest_time
  ✓ input_select: cheap_tariff_windows, heat_pump_consumption_model
  ✓ input_boolean: heating_season_active

7. TROUBLESHOOTING
================================================================================

PROBLEM: Encje się nie pojawiają w HA
------

Rozwiązanie:

  1. Sprawdź logi HA (Settings → System → Administration → Logs)
  2. Przeładuj yaml: Developer Tools → YAML → Reload Helpers
  3. Restart HA: Developer Tools → YAML → Restart Home Assistant
  4. Czekaj 30 sekund
  5. Sprawdzaj Settings → Devices & Services → Helpers


PROBLEM: Zmiany w HA nie są synchronizowane do AppDaemon
------

Sprawdź:

  1. Czy plik ha_sync.py istnieje w apps/pv_planner/?
  2. Czy jest import w pv_planner_app.py?
  3. Czy AppDaemon wczytał ConfigSync()?
  4. Sprawdź logi AppDaemon: czy są błędy?

Jeśli zaś są błędy importu:

  - Upewnij się, że __init__.py istnieje w apps/pv_planner/
  - Sprawdź ścieżkę relativnego importu: "from .ha_sync import ConfigSync"


PROBLEM: Błąd "No such file or directory: config.py"
------

Rozwiązanie:

  1. Sprawdź, czy config.py jest w apps/pv_planner/
  2. Czekaj 30 sekund po dodaniu pliku
  3. Reload AppDaemon


PROBLEM: Współczynniki się nie zmieniają w planie
------

Sprawdź:

  1. Czy zmiana jest w logatach AppDaemon?
  2. Czy następny plan jest obliczany PO zmianie?
  3. Czy baza danych (plans.db) zawiera nowy plan?

Aby wymusić obliczenie nowego planu:

  - Włącz trigger: input_boolean.pv_planner_test_trigger → ON


PROBLEM: AppDaemon się restartuje od razu po starcie
------

Przyczyny:

  1. Błąd importu ha_sync - sprawdź logi
  2. Brakujący __init__.py
  3. Błąd składni w pv_planner_app.py

Rozwiązanie:

  docker logs appdaemon -f

8. FAQ
================================================================================

P: Czy muszę edytować config.py, aby zmienić parametry?
O: Nie! Wszystkie parametry są dostępne w HA. Edytuj suwaki w Settings.

P: Co się stanie, jeśli zmienię współczynnik PV w trakcie dnia?
O: Następny plan (D+1) będzie obliczony z nowym współczynnikiem automatycznie.

P: Czy mogę zmienić taryfy prądowe na locie?
O: Tak, ale tylko dla następnego planu. Bieżący plan już został wysłany.

P: Co to SOC_06 i SOC_13?
O: Docelowy poziom baterii o godzinie 6:00 i 13:00, obliczony symulacją 24h.

P: Dlaczego współczynniki to 0.60/0.40?
O: Doświadczalne wartości - rano jest więcej chmur, popołudnie czystsze.

P: Czy mogę konfigurować APP bez Home Assistant?
O: Tak, edytując bezpośrednio config.py (ale bez synchronizacji w realtime).

P: Co to pMP (pompa ciepła)?
O: System grzewczy, którego moc zależy od temperatury zewnętrznej.

P: Jak długo trwa obliczenie planu?
O: ~1-2 sekundy (symulacja 24h + walidacja SOC).

P: Como zmienić czasy programów 3 i 6?
O: Użyj encji input_text w formacie HH:MM (np. "06:05").
   input_text.pv_planner_program_3_earliest_time i program_6_earliest_time

P: Czy mogę zmienić moc pompy na rozne temperatury niezależnie?
O: Tak! Każda temperatura ma oddzielny suwak input_number.
   pv_planner_heat_pump_power_at_plus_15/plus_10/plus_5/0/minus_5/minus_10

P: Co się stanie gdy zmienię sezon grzewczy na OFF?
O: config.HEATING_SEASON_ACTIVE = False. Sterowanie grzewaniem jest wyłączone.
